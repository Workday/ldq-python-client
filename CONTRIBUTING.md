# Contributing

Thank you for your interest in the Workday Live Data Query (LDQ) Python Client.

This project is licensed under the [Apache License, Version 2.0](LICENSE). See [NOTICE](NOTICE) for third-party attribution.

## Read-only public repository

This repository is published as a **read-only** open source mirror for partners and the community to **view source, build, and use** the client under the Apache 2.0 license.

**External contributions are not accepted here** (no pull requests). Development happens in Workday’s internal repositories; updates are published to this mirror on a release cadence.

For questions or defects, use your usual Workday support or partner channels—not GitHub issues on this mirror, unless Workday enables them later.

For build and test instructions, see [README](README.md).
